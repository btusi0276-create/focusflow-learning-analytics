# FocusFlow：个人学习行为数据分析项目

> FocusFlow 是一个关注隐私保护的个人学习行为分析项目。
> 它通过记录睡眠、学习、手机使用、运动和课程负担等日常行为，
> 探索这些因素与学习专注状态、深度学习时长之间的关系。

## 项目背景

很多学生会感到“学习效率不高”，但很难基于真实数据判断：
究竟是睡眠不足、手机使用过多、课程压力，还是其他日常习惯影响了自己的专注状态。

本项目通过持续记录匿名化的个人学习行为数据，建立可复现的数据清洗、
可视化与分析流程，并最终开发一个交互式学习行为洞察工具。

## 研究问题

1. 睡眠时长和睡眠质量，与当天的专注评分和深度学习时长有什么关系？
2. 娱乐手机使用时长，是否与深度学习时长和专注评分存在关联？
3. 运动、课程负担和星期几，是否与高专注学习日有关？

## 数据字段

- 日期
- 昨晚睡眠时长（小时）
- 睡眠质量
- 总学习时长（小时）
- 深度学习时长（小时）
- 娱乐手机时长（小时）
- 运动时长（小时）
- 课程负担
- 今日专注评分
- 今日备注

## 如何运行 / How to Run

### 1. 克隆项目

```bash
git clone https://github.com/btusi0276-create/focusflow-learning-analytics.git
cd focusflow-learning-analytics
```

### 2. 创建并启用虚拟环境

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 安装项目依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 验证公开样例数据

```bash
python src/data_validation.py
```

预期输出：

```text
✅ 数据质量检查通过：12 条记录、10 个字段均符合当前规则。
```

也可以显式指定输入文件：

```bash
python src/data_validation.py --input data/sample_learning_log.csv
```

### 5. 验证本地个人数据

个人原始数据应保存在本地的 `data/private/` 文件夹中，且不会上传至公开仓库。

当本地存在个人数据文件后，可运行：

```bash
python src/data_validation.py --input data/private/my_learning_log.csv
```

使用下面的命令查看验证器支持的参数：

```bash
python src/data_validation.py --help
```

## 数据质量检查

`src/data_validation.py` 会检查：

- 必要字段是否完整；
- 日期是否有效，以及是否存在重复日期；
- 睡眠、学习、手机使用和运动时长是否处于合理范围；
- 睡眠质量和专注评分是否为 1–5；
- 课程负担是否为“低”“中”或“高”；
- 深度学习时长是否超过总学习时长。
